Technical FAQ

Minimum requirements

  • Minecraft Java Edition 1.20.1
  • Java 17 or newer
  • 4 GB RAM allocated to Minecraft (6–8 GB recommended)
  • A GPU that supports OpenGL 3.2 or newer

Common issues

The game crashes on launch.
Make sure you have at least 4 GB of RAM allocated in your launcher settings. Check the crash log in .minecraft/crash-reports/ and post it in the Discord or on the Modrinth page.
Which mod loader does the pack use?
[Mod loader TBD — will be updated before release.] The modpack installer will handle this automatically if you use the Modrinth App, CurseForge, or Prism Launcher.
Can I add more mods?
You can, but compatibility is not guaranteed. The modpack is a curated experience; extra mods may cause conflicts or break world generation. Test on a separate profile.
Still stuck?
Ask in the Discord or leave a comment on Modrinth.
