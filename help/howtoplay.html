How to Play

Requirements

  • Minecraft Java Edition 1.20.1
  • A compatible mod launcher (Modrinth App, CurseForge, or Prism Launcher recommended)
  • At least 4 GB of RAM allocated to Minecraft (6–8 GB recommended)
  • Java 17 or newer

Installing via Modrinth App

  1. Download and install the Modrinth App.
  2. Search for Gamma Files in the Browse tab, or open the modpack page directly.
  3. Click Install and wait for the download to complete.
  4. Click Play. The launcher will handle Java and dependencies automatically.

Installing via CurseForge

  1. Open the CurseForge App.
  2. Go to Minecraft → Browse Modpacks and search for Gamma Files.
  3. Click Install and then Play.

Manual installation

If you prefer to install manually, download the modpack .mrpack or .zip file from Modrinth or CurseForge, then import it in your launcher of choice (Prism Launcher supports .mrpack natively).

First steps in-game

  • Keep an eye on unusual terrain features — some structures are easy to miss if you're moving fast.
  • Music discs can be found in unexpected places. Try them all.
  • Caves are deeper than you expect. Bring torches. Bring more torches.
  • If something looks wrong, it probably is.

Reporting issues

If you find a bug or something that seems unintentionally broken, please report it on the modpack's Modrinth page or via the community Discord.
